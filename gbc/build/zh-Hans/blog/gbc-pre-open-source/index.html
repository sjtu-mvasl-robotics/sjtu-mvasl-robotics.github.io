GBC Project Will Soon be Available!

2025年7月31日 · 阅读需 2 分钟
Yifei Yao
GBC Project Lead, SJTU MVASL Lab

We're excited to announce that the GBC (Generalized Behavior Cloning Framework) is in its final stages of preparation for public release! 🎉

📋 Current Status​

Our team is currently conducting comprehensive code review, refinement, and debugging to ensure the highest quality open-source release. We want to make sure that when GBC becomes available, it's ready for researchers and developers worldwide to use effectively.

🗓️ Release Timeline​

Target Release Date: Before August 10, 2025 📅

The complete GBC framework will be available at: https://github.com/sjtu-mvasl-robotics/GBC

📄 Paper & Code Release​

The open-source code release is planned to coincide with our research paper publication on arXiv. Both the technical documentation and the complete implementation will be available simultaneously, providing you with:

  • 📚 Comprehensive documentation (like this site!)
  • 🛠️ Complete source code with examples
  • 🤖 Robot configuration templates for multiple platforms
  • 📖 Academic paper with detailed methodology

🙏 Thank You for Your Interest!​

We're incredibly grateful for the enthusiasm and interest the robotics community has shown in GBC. Your support motivates us to deliver the best possible framework for humanoid robot learning and motion imitation.

🔔 Stay Updated​

  • ⭐ Star our repository: https://github.com/sjtu-mvasl-robotics/GBC
  • 📖 Follow our documentation progress on this site
  • 🗨️ Join our GitHub Discussions for early access to development updates

The future of humanoid robotics is almost here! 🤖✨

Stay tuned for the official release announcement!
